Final-year project

A distributed intelligent agent platform — my final-year project at the University of Lahore, built with my project team. EventHive AI

Live site

A multi-agent event-planning app: one Event Manager agent delegates in parallel to specialist Planning, Budget and Logistics agents, then validates everything into a single coordinated plan. You describe the event — type, attendees, date, location, budget and goals — and the hive builds the plan on the server before anything is marked complete.

Python · Multi-agent orchestration · REST API · Vercel
